# Contributing / Contribuindo

**English** | [Português](#português)

Thanks for helping improve CutClips.

- **Bugs and ideas:** open an [issue](https://github.com/CodaxiKing/CutClips/issues).
- **Improvements:** fork the repository, create a branch, run the tests
  (`.venv\Scripts\python.exe -P -m pytest -q`) and open a pull request.

### Licensing of contributions

CutClips is distributed under the MIT License with the Commons Clause, which
does not allow third parties to sell it.

By submitting a contribution, you:

1. license it to the maintainer, Diego Tavares (CodaxiKing), under the
   [MIT License](https://opensource.org/license/mit), so it can be included in
   the project and in any future version of it, under any license the
   maintainer chooses;
2. keep the copyright of your contribution;
3. confirm that you wrote it, or otherwise have the right to submit it under
   these terms.
