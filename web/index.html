Configuração inicial da conexão Google

Como este aplicativo roda no seu computador, ele precisa de um cliente OAuth do Google. Faça isso apenas uma vez — nenhuma métrica precisa ser digitada.

  1. No Google Cloud, ative YouTube Data API v3, YouTube Analytics API e YouTube Reporting API.
  2. Configure a tela de consentimento e, se o aplicativo estiver em teste, adicione seu e-mail como usuário de teste.
  3. Crie um cliente OAuth do tipo Aplicativo para computador e baixe o JSON. Para um cliente Web, cadastre o retorno .
  4. Importe o arquivo abaixo e clique em Conectar YouTube. Autorize a conta proprietária do canal.

Credenciais protegidas pelo Windows, neste computador. O login deve ser feito em um navegador externo se o Google bloquear o navegador integrado. Aplicativos Google em teste podem exigir reconexão após sete dias.
